# 📚 Study Tutor Agent

A beginner-friendly AI Study Tutor built using:

- Streamlit
- CrewAI
- Groq
- GPT-OSS 120B

## Features

- Ask study questions
- Beginner / Intermediate / Advanced modes
- Conversation memory
- Calculator tool
- Current time tool
- Revision points

## Architecture

Streamlit
↓
CrewAI
↓
Study Tutor Agent
↓
Groq GPT-OSS 120B

## Deployment

The application can be deployed using GitHub and Render.
